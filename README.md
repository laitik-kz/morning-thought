# morning-thought — утренняя мысль разработчика

Одностраничный сайт (HTML + Tailwind CSS v4 через CDN): стеклянная карточка с «утренней мыслью разработчика» на фоне живой SVG-сцены Алматы.

## Что умеет
- 52 мысли на русском, подбор с учётом погоды, времени суток и дня недели (по времени Алматы), без повторов из последних 8.
- «Новая мысль» — переворот карточки, вспышка частиц, котик подпрыгивает. Пробел — тоже новая мысль.
- «Копировать» — цитата в буфер обмена (запасной путь: execCommand, затем выделение текста).
- Погода Алматы из Open-Meteo (бесплатно, без ключа): ясно / облачно / дождь / снег, день и ночь. Днём котик, ночью сова, на горизонте Кок-Тобе.
- Переключатель погоды вручную; если API недоступен — снимок погоды на момент сборки.

## Как запустить локально
Открыть `index.html` двойным кликом в браузере (нужен интернет для шрифтов, Tailwind и погоды).

## Ограничения
- Tailwind Play CDN — по документации только для разработки; для продакшна нужна сборка.
- На ссылке claude.ai внешние запросы запрещены (CSP), там работает снимок погоды и ручной переключатель.
